# User Profile

Невеликий застосунок на React і TypeScript, створений за допомогою Vite. Він завантажує профіль користувача з JSONPlaceholder API та відображає стани завантаження, успіху й помилки.

## Вимоги

- Node.js
- npm

## Встановлення та запуск

Встановіть залежності:

```bash
npm install
```

Запустіть сервер розробки:

```bash
npm run dev
```

Відкрийте адресу, яку Vite покаже в терміналі (зазвичай `http://localhost:5173`).

## Команди

| Команда | Опис |
| --- | --- |
| `npm run dev` | Запускає застосунок у режимі розробки |
| `npm test` | Запускає тести один раз |
| `npx vitest` | Запускає тести в режимі спостереження |
| `npm run build` | Перевіряє TypeScript і збирає застосунок для production |
| `npm run lint` | Перевіряє код за допомогою Oxlint |
| `npm run preview` | Переглядає production-збірку локально |

## Функціональність

Компонент `UserProfile` надсилає GET-запит до `https://jsonplaceholder.typicode.com/users/1`. Під час очікування відповіді відображається індикатор завантаження. Після успішного запиту показуються ім’я та email користувача; у разі HTTP- або мережевої помилки відображається повідомлення про помилку.

Стилі компонента зберігаються у `src/App.css`. Файл підключено в `src/main.tsx`.

## Тести

Тести компонента розташовані в `src/components/UserProfile.test.tsx`. Вони мокують `fetch` і перевіряють:

- індикатор завантаження, поки запит не завершено;
- відображення даних користувача після успішної відповіді;
- повідомлення про HTTP-помилку;
- повідомлення про мережеву помилку.

Vitest запускає тести у середовищі jsdom, а `@testing-library/react` використовується для рендерингу компонента та перевірки інтерфейсу.
